# PLP Python Week 4 Assignment

This project contains a small toolbox and an interactive welcome script.

## Files
- `toolbox.py`: contains simple utility functions for arithmetic and greeting.
- `welcome.py`: asks the user for input and demonstrates the functions in `toolbox.py`.

## Run the program
From the project folder, run:

```bash
python welcome.py
```

## Example
When the program runs, it will ask for your name and two numbers, then it will display:
- addition
- subtraction
- multiplication
- division

## Notes
The functions are intentionally simple and suitable for a beginner Python assignment.
